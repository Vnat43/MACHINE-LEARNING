# Machine Learning Projects Portfolio

Welcome to my Machine Learning portfolio ! This repository contains a collection of my machine learning projects, starting from my early classification models to Kaggle competition entries.

## Projects Overview

### 1. Disaster Tweets Classifier
* **Type:** Natural Language Processing (NLP) / Kaggle Competition
* **Date:** 2026
* **Description:** A text classification model designed to analyze and predict whether a given tweet is about a real disaster or not.

### 2. Hotel Booking Cancellation Predictor
* **Type:** Binary Classification
* **Date:** 2023
* **Description:** My first Machine Learning project. The aim is to predict if a hotel reservation will be canceled or not based on customer and booking data. 

### 3. Titanic Survival Classifier
* **Type:** Binary Classification / Kaggle Competition
* **Date:** 2026
* **Description:** My first Kaggle competition. The model predicts if a person present on the Titanic is dead or alive after the accident, based on real passenger data.
